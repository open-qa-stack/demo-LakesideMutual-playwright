## 1. customer-sign-in-view-policies-and-submit-quote

Sign in, review policies, submit a quote request, and verify it in the management applications (end-to-end level, other, nominal, writes data). Application customer-self-service, domain insurance-quotes, functionality customer-self-service-quote-journey.

- Intent: Verify the customer can authenticate, consult their policy and quote overview, submit a Home Insurance quote, and see the created request reflected in Policy Management and Customer Management.
- Sources: customer-self-service; customer-self-service-db: user_logins; customer-self-service-api; policy-management; customer-management
- Data: "admin@example.com" (customer-self-service); "1password" (customer-self-service); "2026-12-01" (made-up); "Home Insurance" (customer-self-service); "1000 CHF" (customer-self-service)

### Step 1. Open Customer Self-Service login

```ts
await page.goto("/login");
```

Expect 1.1: The login form and demo login option are displayed.
- shows "Log in to your LM account" in `page.getByRole("heading", { name: "Log in to your LM account", exact: true })`
- shows "Email Address" by its text
- shows "Password" by its text
- shows "Fill in" in `page.getByRole("button", { name: "Fill in", exact: true })`

### Step 2. Fill the displayed demo credentials and sign in

```ts
await customerSelfService.login.fillInButton.click();
await customerSelfService.login.logInButton.click();
```

Expect 2.1: The authenticated overview displays quote requests and the customer's policy information.
- shows "Insurance Quote Requests" in `page.getByText("Show archived Insurance Quote Requests", { exact: true })`
- shows "New Insurance Quote Request" in `page.getByRole("button", { name: "New Insurance Quote Request", exact: true })`
- shows "Policies" in `page.getByRole("heading", { name: "Policies", exact: true })`
- shows "Health Insurance" in `page.getByRole("heading", { name: "Health Insurance", exact: true })`
- shows "1500 CHF" in `page.getByText("1500 CHF", { exact: true })`
- shows "250 CHF" in `page.getByText("250 CHF", { exact: true })`

- no longer shows "Log in to your LM account" in `page.getByRole("heading", { name: "Log in to your LM account", exact: true })`

### Step 3. Open the quote request form to review the prefilled personal data

```ts
await customerSelfService.policies.newInsuranceQuoteRequestButton.click();
```

Expect 3.1: The personal data step shows the customer's prefilled contact address and billing address option.
- shows "Contact Address" in `page.getByRole("heading", { name: "Contact Address", exact: true })`
- shows "Oberseestrasse 11" as the value of `page.getByRole("textbox", { name: "Street Address", exact: true })`
- shows "8640" by its text
- shows "Rapperswil" as the value of `page.getByRole("textbox", { name: "City", exact: true })`
- shows "Billing Address" in `page.getByRole("heading", { name: "Billing Address", exact: true })`
- shows "Same as Contact Address" in `page.getByText("Same as Contact Address", { exact: true })`
- shows "Next" in `page.getByRole("button", { name: "Next", exact: true })`

### Step 4. Advance to insurance configuration, enter the start date, choose Home Insurance and a 1000 CHF deductible, then advance to confirmation

```ts
await customerSelfService.policiesNewInsuranceQuoteRequest.nextButton.click();

await customerSelfService.policiesNewInsuranceQuoteRequest.element1000ChfOption.click();

```

Expect 4.1: The confirmation summarizes the chosen date, insurance type and deductible.
- shows "Personal Data" in `page.getByRole("heading", { name: "Personal Data", exact: true })`
- shows "Insurance" in `page.getByRole("heading", { name: "Insurance", exact: true })`
- shows "01.12.2026" in `page.getByRole("cell", { name: "01.12.2026", exact: true })`
- shows "Home Insurance" in any of the 36 `page.getByRole("cell", { name: "Home Insurance", exact: true })`
- shows "1000 CHF" in `page.getByRole("cell", { name: "1000 CHF", exact: true })`
- shows "Request a Quote" in `page.getByRole("button", { name: "Request a Quote", exact: true })`

### Step 5. Submit the quote request and verify the created request in Policy Management

```ts
await customerSelfService.policiesNewInsuranceQuoteRequest.requestAQuoteButton.click();

await policyManagement.home.insuranceQuoteRequestsLink.click();
```

Expect 5.1: The request appears in Policy Management as an open Home Insurance request for Max Mustermann.
- shows "Insurance Quote Requests" in `page.getByRole("heading", { name: "Insurance Quote Requests", exact: true })`
- shows "19. Nov 2026 01:55" in `page.getByRole("cell", { name: "19. Nov 2026 01:55", exact: true })`
- shows "Max Mustermann" in `page.getByRole("row", { name: "15. Nov 2026 19:44" }).getByRole("link", { name: "Max Mustermann", exact: true })`
- shows "Home Insurance" in any of the 36 `page.getByRole("cell", { name: "Home Insurance", exact: true })`
- shows "Request open" in any of the 29 `page.getByRole("cell", { name: "Request open", exact: true })`
