## 1. submit-quote-request

Sign in and submit a home insurance quote request (business level, other, nominal, writes data). Application customer-self-service, domain insurance-quotes, functionality quote-request-submission.

- Intent: Verify that a signed-in customer can complete the quote request wizard and see the newly submitted request and its details in their account.
- Sources: customer-self-service; customer-self-service-api: insurance-quotes
- Data: "admin@example.com" (customer-self-service); "1password" (customer-self-service); "Oberseestrasse 11" (customer-self-service); "8640" (customer-self-service); "Rapperswil" (customer-self-service); "2026-11-18" (customer-self-service); "Home Insurance" (customer-self-service); "500 CHF" (customer-self-service)

### Step 1. Open Customer Self-Service at its current policies page, which already contains the submitted quote from exploration

```ts
await page.goto("/");
```

Expect 1.1: The page displays the submitted quote that can be opened to inspect its details.
- shows "18. Nov 2026" in `page.getByRole("cell", { name: "18. Nov 2026", exact: true })`
- shows "Home Insurance" in `page.getByText("18. Nov 2026Home InsuranceWaiting for Quote", { exact: true })`
- shows "Waiting for Quote" in `page.getByText("18. Nov 2026Home InsuranceWaiting for Quote", { exact: true })`

### Step 2. Open the submitted request details

```ts
await customerSelfService.policies.element18Nov2026homeInsurancewaitingForText.click();
```

Expect 2.1: The request detail displays its deductible and pending response status.
- shows "18. Nov 2026 20:56:" in `page.getByText("18. Nov 2026 20:56:", { exact: true })`
- shows "500 CHF" in `page.getByRole("cell", { name: "500 CHF", exact: true })`
- shows "Lakeside Mutual has not yet responded to this Insurance Quote Request." in `page.getByText("Lakeside Mutual has not yet responded to this Insurance Quote Request.", { exact: true })`

### Step 3. Return to the quote request list

```ts
await customerSelfService.policiesNewInsuranceQuoteRequest.insuranceQuoteRequestsLink.click();
```

Expect 3.1: The submitted request remains visible in the list.
- shows "18. Nov 2026" in `page.getByRole("cell", { name: "18. Nov 2026", exact: true })`
- shows "Home Insurance" in `page.getByText("18. Nov 2026Home InsuranceWaiting for Quote", { exact: true })`
- shows "Waiting for Quote" in `page.getByText("18. Nov 2026Home InsuranceWaiting for Quote", { exact: true })`
- no longer shows "Insurance Quote Request Details" in `page.getByText("Insurance Quote Request Details", { exact: true })`
