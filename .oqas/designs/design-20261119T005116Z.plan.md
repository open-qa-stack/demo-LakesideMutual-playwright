## 1. customer-login-and-view-policies

Sign in and review the customer’s insurance policies (business level, other, nominal, writes data). Application customer-self-service, domain policies, functionality customer-policy-overview.

- Intent: Verify that the demo customer can sign in, see their quote-request overview, and inspect the policy coverage information shown in the self-service portal; sign-in may update authentication state.
- Sources: customer-self-service; customer-self-service-api
- Data: "admin@example.com" (customer-self-service); "1password" (customer-self-service)

### Step 1. Open Customer Self-Service and enter the login screen

```ts
await page.goto("/");
await customerSelfService.home.logInToAccessYourButton.click();
```

Expect 1.1: The login screen provides the demo credentials and sign-in controls.
- shows "Log in to your LM account" in `page.getByRole("heading", { name: "Log in to your LM account", exact: true })`
- shows "Email Address" by its text
- shows "Password" by its text
- shows "admin@example.com1password" in `page.getByText("admin@example.com1password", { exact: true })`

### Step 2. Fill the demo credentials and sign in

```ts
await customerSelfService.login.fillInButton.click();
await customerSelfService.login.logInButton.click();
```

Expect 2.1: The signed-in portal displays the quote requests and the customer’s policy coverage.
- shows "Insurance Quote Requests" in `page.getByText("Show archived Insurance Quote Requests", { exact: true })`
- shows "19. Nov 2026" in any of the 6 `page.getByRole("cell", { name: "19. Nov 2026", exact: true })`
- shows "Home Insurance" in any of the 20 `page.getByRole("cell", { name: "Home Insurance", exact: true })`
- shows "Waiting for Quote" in any of the 27 `page.getByRole("cell", { name: "Waiting for Quote", exact: true })`
- shows "Policies" in `page.getByRole("heading", { name: "Policies", exact: true })`
- shows "Health Insurance" in `page.getByRole("heading", { name: "Health Insurance", exact: true })`
- shows "05. Feb 2018 – 10. Feb 2018" in `page.getByText("05. Feb 2018 – 10. Feb 2018", { exact: true })`
- shows "1500 CHF" in `page.getByText("1500 CHF", { exact: true })`
- shows "250 CHF" in `page.getByText("250 CHF", { exact: true })`
- shows "1000000 CHF" in `page.getByText("1000000 CHF", { exact: true })`
- shows "N/A" by its text
