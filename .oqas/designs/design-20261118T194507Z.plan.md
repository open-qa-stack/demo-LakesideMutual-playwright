## 1. customer-profile-edit-three-apps

Search for a customer, update the email, and check the saved profile across applications (end-to-end level, other, nominal, writes data). Application customer-management, domain customers, functionality customer-profile-edit.

- Intent: Verify the Customer Management search and profile-edit journey and validate the updated customer contact in Policy Management and the customer profile in Customer Self-Service, then restore the original email.
- Sources: customer-management; policy-management; customer-self-service; customer-management-api
- Data: "Ado" (customer-management); "ado.kinnett.updated@example.com" (made-up); "akinnetta@example.com" (customer-management)

### Step 1. Open Customer Management and search for Ado

```ts
await page.goto("/");
await customerManagement.home.searchTextbox.fill("Ado");
await customerManagement.home.searchButton.click();
```

Expect 1.1: The filtered customer list contains Ado Kinnett and one matching result.
- shows "Ado Kinnett" in `page.getByRole("cell", { name: "Ado Kinnett", exact: true })`
- shows "1 - 1 of 1" in `page.getByRole("columnheader", { name: "1 - 1 of 1", exact: true })`
- no longer shows "Bel Pifford" in `page.getByRole("cell", { name: "Bel Pifford", exact: true })`

### Step 2. Open Ado Kinnett's profile and verify the current contact details

```ts
await customerManagement.home.showButtonInRow("Ado Kinnett").click();
```

Expect 2.1: The profile shows the current email, address, and phone number.
- shows "Ado Kinnett" in any of the 2 `page.getByText("Ado Kinnett", { exact: true })`
- shows "akinnetta@example.com" in `page.getByRole("link", { name: "akinnetta@example.com", exact: true })`
- shows "28 Cross-Application Avenue, 3000 Bern" in any of the 22 `page.getByText("28 Cross-Application Avenue, 3000 Bern", { exact: true })`
- shows "055 222 41 11" in `page.getByText("055 222 41 11", { exact: true })`

### Step 3. Open the profile editor and save the updated email address

```ts
await customerManagement.customersItem.editProfileButton.click();
await customerManagement.customersItemEditProfile.emailAddressTextbox.fill("ado.kinnett.updated@example.com");
await customerManagement.customersItemEditProfile.saveChangesButton.click();
```

Expect 3.1: The profile displays the newly saved email address.
- shows "ado.kinnett.updated@example.com" in `page.getByRole("link", { name: "ado.kinnett.updated@example.com", exact: true })`
- no longer shows "akinnetta@example.com" in `page.getByRole("link", { name: "akinnetta@example.com", exact: true })`

### Step 4. Open Policy Management and verify Ado Kinnett's customer entry

```ts
await policyManagementPage.goto(new URL("/customers", process.env.OQAS_BASE_URL_POLICY_MANAGEMENT).href);
```

Expect 4.1: Policy Management displays Ado Kinnett in its customer list.
- shows "Ado Kinnett" in `page.getByRole("cell", { name: "Ado Kinnett", exact: true })`

### Step 5. Open Customer Self-Service and view the signed-in customer's profile

```ts
await customerSelfServicePage.goto(new URL("/", process.env.OQAS_BASE_URL_CUSTOMER_SELF_SERVICE).href);
await customerSelfService.policies.myProfileLink.click();
```

Expect 5.1: Customer Self-Service displays the signed-in customer's profile details.
- shows "Max Mustermann" in `page.getByText("Max Mustermann", { exact: true })`
- shows "Oberseestrasse 11, 8640 Rapperswil" in `page.getByText("Oberseestrasse 11, 8640 Rapperswil", { exact: true })`
- shows "admin@example.com" in `page.getByRole("link", { name: "admin@example.com", exact: true })`
- shows "055 222 41 11" in `page.getByText("055 222 41 11", { exact: true })`

### Step 6. Restore Ado Kinnett's original email by reopening the editor and saving it (restores: run even after a failure)

```ts
await page.goto("/customers/bunlo9vk5f/edit_profile");
await customerManagement.customersItemEditProfile.emailAddressTextbox.fill("akinnetta@example.com");
await customerManagement.customersItemEditProfile.saveChangesButton.click();
```

Expect 6.1: The profile displays the original email address after restoration.
- shows "akinnetta@example.com" in `page.getByRole("link", { name: "akinnetta@example.com", exact: true })`
- no longer shows "ado.kinnett.updated@example.com" in `page.getByRole("cell", { name: "ado.kinnett.updated@example.com", exact: true })`
