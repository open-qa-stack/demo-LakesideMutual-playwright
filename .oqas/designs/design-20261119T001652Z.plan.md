## 1. cross-app-quote-request-to-review

Submit a quote request and verify it appears for Policy Management review (cross-application level, other, nominal, writes data). Application customer-self-service, domain insurance-quotes, functionality quote-request-review.

- Intent: Verify that submitting an insurance quote request in Customer Self-Service creates an open request visible to staff in Policy Management.
- Sources: policy-management-specs: policy-management-frontend.md § PMF-UC-08 — Review insurance quote requests; customer-self-service: /policies/new-insurance-quote-request; policy-management: /insurance-quote-requests
- Data: "Home Insurance" (customer-self-service); "1000 CHF" (customer-self-service); "8640" (customer-self-service); "Oberseestrasse 11" (customer-self-service); "Rapperswil" (customer-self-service); "19.11.2026" (customer-self-service)

### Step 1. Sign in to Customer Self-Service and open the policies and quote-request page

```ts
await page.goto("/policies");
await customerSelfService.login.emailAddressTextbox.fill(process.env.CSS_DEMO_USERNAME!);
await customerSelfService.login.passwordTextbox.fill(process.env.CSS_DEMO_PASSWORD!);
await customerSelfService.login.logInButton.click();
```

Expect 1.1: The customer policies and quote requests page is displayed.
- shows "Insurance Quote Requests" in `page.getByText("Show archived Insurance Quote Requests", { exact: true })`
- shows "Policies" in `page.getByRole("heading", { name: "Policies", exact: true })`

### Step 2. Start a new insurance quote request and advance to the insurance step

```ts
await customerSelfService.policies.newInsuranceQuoteRequestButton.click();
await customerSelfService.policiesNewInsuranceQuoteRequest.nextButton.click();
```

Expect 2.1: The insurance configuration step is displayed.
- shows "Start Date" in `page.getByText("Start Date", { exact: true })`
- shows "Insurance Type" in `page.getByText("Insurance Type", { exact: true })`
- shows "Deductible" in `page.getByText("Deductible", { exact: true })`

### Step 3. Select Home Insurance and a deductible of 1000 CHF, then advance to confirmation

```ts
await customerSelfService.policiesNewInsuranceQuoteRequest.insuranceTypelifeInsurancehomeInsurancehealthInsurancecarText.click();
await customerSelfService.policiesNewInsuranceQuoteRequest.homeInsuranceOption.click();
await customerSelfService.policiesNewInsuranceQuoteRequest.deductible300Chf500Chf1000Chf1500Chf2000Text.click();
await customerSelfService.policiesNewInsuranceQuoteRequest.element1000ChfOption.click();
await customerSelfService.policiesNewInsuranceQuoteRequest.nextButton.click();
```

Expect 3.1: The confirmation summarizes the request for Home Insurance with a 1000 CHF deductible and the selected start date.
- shows "Home Insurance" in any of the 26 `page.getByRole("cell", { name: "Home Insurance", exact: true })`
- shows "1000 CHF" in `page.getByRole("cell", { name: "1000 CHF", exact: true })`
- shows "19.11.2026" in `page.getByRole("cell", { name: "19.11.2026", exact: true })`

### Step 4. Submit the quote request and verify its new row in Policy Management

```ts
await customerSelfService.policiesNewInsuranceQuoteRequest.requestAQuoteButton.click();
await policyManagementPage.goto(new URL("/insurance-quote-requests", process.env.OQAS_BASE_URL_POLICY_MANAGEMENT).href);
```

Expect 4.1: Policy Management lists the submitted Home Insurance request as open.
- shows "Insurance Quote Requests" in `page.getByRole("heading", { name: "Insurance Quote Requests", exact: true })`
- shows "Home Insurance" in any of the 26 `page.getByRole("cell", { name: "Home Insurance", exact: true })`
- shows "Request open" in any of the 21 `page.getByRole("cell", { name: "Request open", exact: true })`

## 2. cross-app-policy-visible-in-self-service

Verify the managed policy is visible to its customer (cross-application level, other, nominal, writes data). Application policy-management, domain policies, functionality customer-policy-visibility.

- Intent: Verify that a policy managed in Policy Management is reflected in the customer's policy information in Customer Self-Service; signing in only establishes the session and is included as a write scenario for test repeatability.
- Sources: policy-management-specs: policy-management-frontend.md § PMF-SCR-02 — Policy detail; policy-management: /policies/fvo5pkqerr; customer-self-service: /policies
- Data: "fvo5pkqerr" (policy-management-db); "Health Insurance" (policy-management); "250 CHF" (policy-management); "1000000 CHF" (policy-management); "1500 CHF" (policy-management)

### Step 1. Open the policy detail in Policy Management and confirm its customer and coverage information

```ts
await page.goto("/");
await policyManagement.home.showDetailsButton.click();
await policyManagement.insuranceQuoteRequestsItem.policiesLink.click();
await policyManagement.home.showDetailsButton.click();
```

Expect 1.1: The policy detail shows the policy and the listed coverage amounts for Max Mustermann.
- shows "Health Insurance" in `page.getByRole("heading", { name: "Health Insurance", exact: true })`
- shows "Max Mustermann" in `page.getByRole("link", { name: "Max Mustermann", exact: true })`
- shows "1500 CHF" in `page.getByText("1500 CHF", { exact: true })`
- shows "250 CHF" in `page.getByText("250 CHF", { exact: true })`
- shows "1000000 CHF" in `page.getByText("1000000 CHF", { exact: true })`

### Step 2. Sign in and view the customer's policy list in Customer Self-Service; the sign-in establishes the session without changing the policy data

```ts
await customerSelfServicePage.goto(new URL("/policies", process.env.OQAS_BASE_URL_CUSTOMER_SELF_SERVICE).href);
await customerSelfService.login.emailAddressTextbox.fill(process.env.CSS_DEMO_USERNAME!);
await customerSelfService.login.passwordTextbox.fill(process.env.CSS_DEMO_PASSWORD!);
await customerSelfService.login.logInButton.click();
await customerSelfServicePage.goto(new URL("/policies", process.env.OQAS_BASE_URL_CUSTOMER_SELF_SERVICE).href);
```

Expect 2.1: Customer Self-Service displays the Health Insurance policy with matching deductible, premium and policy limit.
- shows "Health Insurance" in `page.getByRole("heading", { name: "Health Insurance", exact: true })`
- shows "1500 CHF" in `page.getByText("1500 CHF", { exact: true })`
- shows "250 CHF" in `page.getByText("250 CHF", { exact: true })`
- shows "1000000 CHF" in `page.getByText("1000000 CHF", { exact: true })`

## Not covered

The brief asks what follows, and no scenario does it:

- Créer ou modifier un contrat dans Policy Management et vérifier son effet dans une autre application. L’interface Customer Self-Service consultée est en lecture seule pour les polices; aucun contrôle n’y permet d’observer une création ou modification de police.
- Répondre à une demande de devis dans Policy Management et vérifier son effet dans une autre application. Le formulaire de réponse a deux champs « Amount in CHF » identiques sans libellé/test id unique, ce qui empêche une saisie fiable par le test et donc la vérification de cet effet dans une autre application.
