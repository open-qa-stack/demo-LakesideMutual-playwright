## 1. customer-search-profile-edit-email-address

Search for a customer, open the profile, and update the email address (business level, other, nominal, writes data). Application customer-management, domain customers, functionality customer-profile-edit.

- Intent: Verify the customer-management journey of finding a matching customer, opening their profile, and saving an updated email address; this exercises a contact field not covered by the existing phone-number edit test.
- Sources: customer-management: Customer list, customer profile, and profile editor screens; customer-management-api: PUT /customers/{customerId}
- Data: "Ado" (customer-management); "Ado Kinnett" (customer-management); "akinnetta@example.com" (customer-management); "28 Cross-Application Avenue, 3000 Bern" (customer-management); "ado.kinnett.updated@example.com" (made-up)

### Step 1. Open the customer list

```ts
await page.goto("/");
```

Expect 1.1: The customer list shows Ado Kinnett and the current email address.
- shows "Customers" in `page.getByRole("heading", { name: "Customers", exact: true })`
- shows "Ado Kinnett" in `page.getByRole("cell", { name: "Ado Kinnett", exact: true })`
- shows "akinnetta@example.com" in `page.getByRole("cell", { name: "akinnetta@example.com", exact: true })`

### Step 2. Search by the customer's first-name fragment and submit the search

```ts
await customerManagement.home.searchTextbox.fill("Ado");
await customerManagement.home.searchButton.click();
```

Expect 2.1: Only the matching customer is returned.
- shows "Ado Kinnett" in `page.getByRole("cell", { name: "Ado Kinnett", exact: true })`
- shows "1 - 1 of 1" in `page.getByRole("columnheader", { name: "1 - 1 of 1", exact: true })`
- no longer shows "Bel Pifford" in `page.getByRole("cell", { name: "Bel Pifford", exact: true })`

### Step 3. Open the matching customer profile and verify its current email

```ts
await customerManagement.home.showButtonInRow("Ado Kinnett").click();
```

Expect 3.1: The profile shows the current email address.
- shows "akinnetta@example.com" in `page.getByRole("link", { name: "akinnetta@example.com", exact: true })`

### Step 4. Open the editor, enter the made-up updated email, and save the profile

```ts
await customerManagement.customersItem.editProfileButton.click();
await customerManagement.customersItemEditProfile.emailAddressTextbox.fill("ado.kinnett.updated@example.com");
await customerManagement.customersItemEditProfile.saveChangesButton.click();
```

Expect 4.1: The profile displays the saved changed email address.
- shows "ado.kinnett.updated@example.com" in `page.getByRole("link", { name: "ado.kinnett.updated@example.com", exact: true })`
- no longer shows "akinnetta@example.com" in `page.getByRole("link", { name: "akinnetta@example.com", exact: true })`

### Step 5. Start restoration by opening the editor route, enter the original email, and save it to restore the record (restores: run even after a failure)

```ts
await page.goto("/customers/bunlo9vk5f/edit_profile");
await customerManagement.customersItemEditProfile.emailAddressTextbox.fill("akinnetta@example.com");
await customerManagement.customersItemEditProfile.saveChangesButton.click();
```

Expect 5.1: The profile displays the restored original email address.
- shows "akinnetta@example.com" in `page.getByRole("link", { name: "akinnetta@example.com", exact: true })`
- no longer shows "ado.kinnett.updated@example.com" in `page.getByRole("link", { name: "ado.kinnett.updated@example.com", exact: true })`
