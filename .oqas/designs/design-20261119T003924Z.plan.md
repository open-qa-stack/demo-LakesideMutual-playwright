## 1. edit-customer-contact-details-shared-across-apps

Search for a customer, update contact details, and verify them across applications (end-to-end level, other, nominal, writes data). Application customer-management, domain customers, functionality customer-profile-management.

- Intent: Verify the end-to-end customer-management journey of finding Ado Kinnett, opening and updating the profile, and confirming the saved contact details are reflected in Policy Management and Customer Self-Service.
- Sources: customer-management: /customers/:id; customer-management: /customers/:id/edit_profile; policy-management: customer profile screen; customer-self-service: /profile
- Data: "Kinnett" (customer-management); "Ado Kinnett" (customer-management); "bunlo9vk5f" (customer-management); "29 Cross-Application Avenue" (customer-management); "3000" (customer-management); "Bern" (customer-management); "ado.kinnett@example.com" (customer-management); "055 222 41 13" (customer-management)

### Step 1. Open the Customer Management customer list

```ts
await page.goto("/");
```

Expect 1.1: The list contains Ado Kinnett and shows the initial customer rows.
- shows "Ado Kinnett" in `page.getByRole("cell", { name: "Ado Kinnett", exact: true })`

### Step 2. Search the list for the last-name fragment Kinnett

```ts
await customerManagement.home.searchTextbox.fill("Kinnett");
await customerManagement.home.searchButton.click();
```

Expect 2.1: The search returns only Ado Kinnett.
- shows "Ado Kinnett" in `page.getByRole("cell", { name: "Ado Kinnett", exact: true })`
- shows "1 - 1 of 1" in `page.getByRole("columnheader", { name: "1 - 1 of 1", exact: true })`
- no longer shows "Bel Pifford" in `page.getByRole("cell", { name: "Bel Pifford", exact: true })`

### Step 3. Open Ado Kinnett's customer profile

```ts
await customerManagement.home.showButtonInRow("Ado Kinnett").click();
```

Expect 3.1: The profile shows the customer's current address, email, and phone number.
- shows "Ado Kinnett" in any of the 2 `page.getByText("Ado Kinnett", { exact: true })`

### Step 4. Open the profile edit form

```ts
await customerManagement.customersItem.editProfileButton.click();
```

### Step 7. Sign in to Customer Self-Service and view the profile

```ts
await customerSelfServicePage.goto(new URL("/", process.env.OQAS_BASE_URL_CUSTOMER_SELF_SERVICE).href);

await customerSelfService.login.logInButton.click();
await customerSelfService.policies.myProfileLink.click();
```

Expect 7.1: Customer Self-Service displays the signed-in profile for Max Mustermann with its contact details.
- shows "Customer Profile" by its text
- shows "Max Mustermann" in `page.getByText("Max Mustermann", { exact: true })`
- shows "Oberseestrasse 11, 8640 Rapperswil" in `page.getByText("Oberseestrasse 11, 8640 Rapperswil", { exact: true })`
- shows "admin@example.com" in `page.getByRole("link", { name: "admin@example.com", exact: true })`
- shows "055 222 41 11" in `page.getByText("055 222 41 11", { exact: true })`
