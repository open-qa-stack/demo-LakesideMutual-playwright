## 1. search-open-edit-customer-profile

Search for a customer, open the profile, and update contact details (business level, other, nominal, writes data). Application customer-management, domain customers, functionality customer-profile-management.

- Intent: Verify the customer-management journey can find a customer by a distinguishing name fragment, show the profile, save changed contact details, and display those saved details on the profile.
- Sources: customer-management; customer-management-api: GET /customers and PUT /customers/{customerId}
- Data: "Kinnett" (customer-management); "Ado Kinnett" (customer-management); "29 Cross-Application Avenue" (made-up); "ado.kinnett@example.com" (made-up); "055 222 41 13" (made-up)

### Step 1. Open the Customer Management customer list

```ts
await page.goto("/");
```

Expect 1.1: The customer list is displayed with the customer records.
- shows "Customers" in `page.getByRole("heading", { name: "Customers", exact: true })`
- shows "Ado Kinnett" in `page.getByRole("cell", { name: "Ado Kinnett", exact: true })`

### Step 2. Search for the customer by the last-name fragment Kinnett

```ts
await customerManagement.home.searchTextbox.fill("Kinnett");
await customerManagement.home.searchButton.click();
```

Expect 2.1: The matching customer appears in the results.
- shows "Ado Kinnett" in `page.getByRole("cell", { name: "Ado Kinnett", exact: true })`
- shows "1 - 1 of 1" in `page.getByRole("columnheader", { name: "1 - 1 of 1", exact: true })`

### Step 3. Open Ado Kinnett's customer profile

```ts
await customerManagement.home.showButtonInRow("Ado Kinnett").click();
```

Expect 3.1: The customer's profile displays their current profile and contact information.
- shows "Ado Kinnett" in any of the 2 `page.getByText("Ado Kinnett", { exact: true })`
- shows "Customer Profile" by its text
- shows "28 Cross-Application Avenue, 3000 Bern" in any of the 23 `page.getByText("28 Cross-Application Avenue, 3000 Bern", { exact: true })`
- shows "akinnetta@example.com" in `page.getByRole("link", { name: "akinnetta@example.com", exact: true })`
- shows "055 222 41 12" in `page.getByText("055 222 41 12", { exact: true })`

### Step 4. Open the profile edit form

```ts
await customerManagement.customersItem.editProfileButton.click();
```

Expect 4.1: The edit form is prefilled with customer profile details and offers saving changes.
- shows "First Name" in `page.getByText("First Name", { exact: true })`
- shows "Ado" in `page.getByRole("link", { name: "Ado Kinnett", exact: true })`
- shows "Last Name" in `page.getByText("Last Name", { exact: true })`
- shows "Kinnett" in `page.getByRole("link", { name: "Ado Kinnett", exact: true })`
- shows "Street Address" in `page.getByText("Street Address", { exact: true })`
- shows "28 Cross-Application Avenue" as the value of `page.getByRole("textbox", { name: "Street Address", exact: true })`
- shows "Email Address" in `page.getByText("Email Address", { exact: true })`
- shows "akinnetta@example.com" as the value of `page.getByRole("textbox", { name: "Email Address", exact: true })`
- shows "Phone Number" in `page.getByText("Phone Number", { exact: true })`
- shows "055 222 41 12" as the value of `page.getByRole("textbox", { name: "Phone Number", exact: true })`
- shows "Save Changes" in `page.getByRole("button", { name: "Save Changes", exact: true })`

### Step 5. Change the street address, email address, and phone number, then save the profile

```ts
await customerManagement.customersItemEditProfile.streetAddressTextbox.fill("29 Cross-Application Avenue");
await customerManagement.customersItemEditProfile.emailAddressTextbox.fill("ado.kinnett@example.com");
await customerManagement.customersItemEditProfile.phoneNumberTextbox.fill("055 222 41 13");
await customerManagement.customersItemEditProfile.saveChangesButton.click();
```

Expect 5.1: The profile returns and displays the updated contact details.
- shows "29 Cross-Application Avenue, 3000 Bern" in `page.getByText("29 Cross-Application Avenue, 3000 Bern", { exact: true })`
- shows "ado.kinnett@example.com" in `page.getByRole("link", { name: "ado.kinnett@example.com", exact: true })`
- shows "055 222 41 13" in `page.getByText("055 222 41 13", { exact: true })`

## Not covered

The brief asks what follows, and no scenario does it:

- A search value that matches no customer should produce an empty results view. This is a single-screen search outcome; the requested business-level plan covers the end-to-end customer management journey, while a negative-only search case is left to functional tests.
