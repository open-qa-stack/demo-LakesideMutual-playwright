## 1. quote-submission-options

Review selected insurance options in the quote wizard (functional level, other, nominal, reads data). Application customer-self-service, domain insurance-quotes, functionality quote-request-wizard.

- Intent: The wizard lets a signed-in customer choose an insurance type and deductible and displays them in the confirmation step.
- Sources: customer-self-service-frontend-code: src/pages/MyPolicies/RequestInsuranceQuote/Step2.js; customer-self-service-frontend-code: src/pages/MyPolicies/RequestInsuranceQuote/Step3.js; customer-self-service
- Data: "admin@example.com" (customer-self-service); "1password" (customer-self-service); "Home Insurance" (customer-self-service-frontend-code); "1000 CHF" (customer-self-service-frontend-code)

### Step 1. Sign in and open the quote request wizard from the policies page

```ts
await page.goto("/");
await customerSelfService.home.logInToAccessYourButton.click();
await customerSelfService.login.emailAddressTextbox.fill(process.env.CSS_DEMO_USERNAME!);
await customerSelfService.login.passwordTextbox.fill(process.env.CSS_DEMO_PASSWORD!);
await customerSelfService.login.logInButton.click();
await customerSelfService.policies.newInsuranceQuoteRequestButton.click();
```

Expect 1.1: The request list offers the action to start a new request.
- shows "Insurance Quote Requests" in `page.getByRole("link", { name: "Insurance Quote Requests", exact: true })`
- shows "New Insurance Quote Request" in `page.getByText("New Insurance Quote Request", { exact: true })`

### Step 3. Continue to the confirmation step

```ts

```

- shows "Personal Data" in `page.getByRole("heading", { name: "Personal Data", exact: true })`

- shows "1000 CHF" in `page.getByRole("cell", { name: "1000 CHF", exact: true })`
- shows "Request a Quote" in `page.getByRole("button", { name: "Request a Quote", exact: true })`
