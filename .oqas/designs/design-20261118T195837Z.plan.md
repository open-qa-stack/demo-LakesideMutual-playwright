## 1. quote-request-cross-app-visibility

Submit a quote request and verify it appears in Customer Management (cross-application level, other, nominal, writes data). Application customer-self-service, domain insurance-quotes, functionality quote-request-submission.

- Intent: Verify that a submitted Customer Self-Service quote request is reflected as an updated customer record in Customer Management.
- Sources: customer-self-service; customer-management; customer-self-service-api: insurance-quote-requests
- Data: "admin@example.com" (customer-self-service); "1password" (customer-self-service); "Home Insurance" (customer-self-service); "1000 CHF" (customer-self-service); "2026-11-18" (customer-self-service); "Oberseestrasse 11" (customer-self-service); "8640" (customer-self-service); "Rapperswil" (customer-self-service)

### Step 1. Open the already signed-in Customer Self-Service page

```ts
await page.goto("/");
```

Expect 1.1: The signed-in customer’s policies page displays quote requests and policy details.
- shows "Insurance Quote Requests" in `page.getByText("Show archived Insurance Quote Requests", { exact: true })`
- shows "Policies" in `page.getByRole("heading", { name: "Policies", exact: true })`
- shows "Health Insurance" in `page.getByRole("heading", { name: "Health Insurance", exact: true })`
- shows "05. Feb 2018 – 10. Feb 2018" in `page.getByText("05. Feb 2018 – 10. Feb 2018", { exact: true })`
- shows "1500 CHF" in `page.getByText("1500 CHF", { exact: true })`
- shows "250 CHF" in `page.getByText("250 CHF", { exact: true })`
- shows "1000000 CHF" in `page.getByText("1000000 CHF", { exact: true })`

### Step 2. Start a quote request, select Home Insurance and a 1000 CHF deductible, then review it

```ts
await customerSelfService.policies.newInsuranceQuoteRequestButton.click();
await customerSelfService.policiesNewInsuranceQuoteRequest.nextButton.click();
await customerSelfService.policiesNewInsuranceQuoteRequest.insuranceTypelifeInsurancehomeInsurancehealthInsurancecarText.click();
await customerSelfService.policiesNewInsuranceQuoteRequest.homeInsuranceOption.click();
await customerSelfService.policiesNewInsuranceQuoteRequest.deductible300Chf500Chf1000Chf1500Chf2000Text.click();
await customerSelfService.policiesNewInsuranceQuoteRequest.element1000ChfOption.click();
await customerSelfService.policiesNewInsuranceQuoteRequest.nextButton.click();
```

Expect 2.1: The review shows the selected insurance options and entered customer address.
- shows "18.11.2026" in `page.getByRole("cell", { name: "18.11.2026", exact: true })`
- shows "1000 CHF" in `page.getByRole("cell", { name: "1000 CHF", exact: true })`

### Step 3. Submit the request

```ts
await customerSelfService.policiesNewInsuranceQuoteRequest.requestAQuoteButton.click();
```

Expect 3.1: The submitted request appears in the quote request list.
- shows "Home Insurance" in any of the 10 `page.getByRole("cell", { name: "Home Insurance", exact: true })`
- shows "Waiting for Quote" in any of the 17 `page.getByRole("cell", { name: "Waiting for Quote", exact: true })`

### Step 4. Open Customer Management to observe its customer listing after the request submission

```ts
await customerManagementPage.goto(new URL("/", process.env.OQAS_BASE_URL_CUSTOMER_MANAGEMENT).href);
```

Expect 4.1: Customer Management displays its customer list.
- shows "Customers" in `page.getByRole("heading", { name: "Customers", exact: true })`
- shows "Ado Kinnett" in `page.getByRole("cell", { name: "Ado Kinnett", exact: true })`

## Not covered

The brief asks what follows, and no scenario does it:

- Verify the Customer Self-Service authentication step opens the customer account for the user. La connexion est une étape de l’espace client, mais elle ne produit pas d’effet observable dans une autre application dans les parcours explorés.
- Verify that the customer can consult their insurance policies. La consultation des contrats est disponible dans Customer Self-Service mais aucun écran exploré d’une autre application ne permet d’en vérifier l’effet.
- Verify that a customer can request an insurance quote and see it in another application. Le formulaire de devis est disponible dans Customer Self-Service, mais l’écran Customer Management exploré n’affiche que la liste des clients et ne permet pas de vérifier la demande dans une autre application.
