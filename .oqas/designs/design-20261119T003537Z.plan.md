## 1. update-customer-contact-details-cross-app

Update customer contact details and verify them in Policy Management (cross-application level, other, nominal, writes data). Application customer-management, domain customers, functionality customer-profile-management.

- Intent: Verify that editing Ado Kinnett's contact details in Customer Management persists the update and that Policy Management displays the same updated profile, an effect crossing the two applications.
- Sources: customer-management: Customer Management home and customer profile; customer-management-api: PUT /customers/{customerId}; customer-core-api: GET /customers/{ids}; policy-management: Customer profile screen
- Data: "Kinnett" (customer-management); "Ado Kinnett" (customer-management); "bunlo9vk5f" (customer-management); "31 Cross-Application Avenue" (made-up); "ado.kinnett.qa@example.com" (made-up); "055 222 41 14" (made-up); "29 Cross-Application Avenue" (customer-management); "ado.kinnett@example.com" (customer-management); "055 222 41 13" (customer-management)

### Step 1. Open the Customer Management home page and locate the Customers list

```ts
await page.goto("/");
```

Expect 1.1: The Customer Management customer list is shown with Ado Kinnett.
- shows "Customers" in `page.getByRole("heading", { name: "Customers", exact: true })`
- shows "Ado Kinnett" in `page.getByRole("cell", { name: "Ado Kinnett", exact: true })`

### Step 2. Search for Ado Kinnett by the last-name fragment Kinnett

```ts
await customerManagement.home.searchTextbox.fill("Kinnett");
await customerManagement.home.searchButton.click();
```

Expect 2.1: The search narrows the list to Ado Kinnett.
- shows "Ado Kinnett" in `page.getByRole("cell", { name: "Ado Kinnett", exact: true })`
- shows "1 - 1 of 1" in `page.getByRole("columnheader", { name: "1 - 1 of 1", exact: true })`
- no longer shows "Bel Pifford" in `page.getByRole("cell", { name: "Bel Pifford", exact: true })`

### Step 3. Open Ado Kinnett's customer profile

```ts
await customerManagement.home.showButtonInRow("Ado Kinnett").click();
```

Expect 3.1: The customer profile shows the existing contact details before editing.
- shows "Ado Kinnett" in any of the 2 `page.getByText("Ado Kinnett", { exact: true })`
- shows "29 Cross-Application Avenue, 3000 Bern" in `page.getByText("29 Cross-Application Avenue, 3000 Bern", { exact: true })`
- shows "ado.kinnett@example.com" in `page.getByRole("link", { name: "ado.kinnett@example.com", exact: true })`
- shows "055 222 41 13" in `page.getByText("055 222 41 13", { exact: true })`

### Step 4. Open the profile edit form

```ts
await customerManagement.customersItem.editProfileButton.click();
```

Expect 4.1: The edit form is displayed with the customer's identity and profile fields.
- shows "Ado Kinnett" in `page.getByRole("link", { name: "Ado Kinnett", exact: true })`
- shows "Street Address" in `page.getByText("Street Address", { exact: true })`
- shows "Email Address" in `page.getByText("Email Address", { exact: true })`
- shows "Phone Number" in `page.getByText("Phone Number", { exact: true })`
- shows "Save Changes" in `page.getByRole("button", { name: "Save Changes", exact: true })`

### Step 5. Replace the street address, email address, and phone number, then save the profile

```ts
await customerManagement.customersItemEditProfile.streetAddressTextbox.fill("29 Cross-Application Avenue");
await customerManagement.customersItemEditProfile.emailAddressTextbox.fill("ado.kinnett@example.com");
await customerManagement.customersItemEditProfile.phoneNumberTextbox.fill("055 222 41 13");
await customerManagement.customersItemEditProfile.saveChangesButton.click();
```

Expect 5.1: The edit form closes after saving the contact changes.
- shows "Ado Kinnett" in any of the 2 `page.getByText("Ado Kinnett", { exact: true })`
- shows "Customer Profile" by its text
- shows "Edit Profile" in `page.getByRole("button", { name: "Edit Profile", exact: true })`
- no longer shows "Save Changes" in `page.getByRole("button", { name: "Save Changes", exact: true })`

### Step 6. Open Ado Kinnett's profile in Policy Management and verify the changed details are shared there

```ts
await policyManagementPage.goto(new URL("/customers/bunlo9vk5f", process.env.OQAS_BASE_URL_POLICY_MANAGEMENT).href);
```

Expect 6.1: Policy Management shows the contact values saved in Customer Management.
- shows "Ado Kinnett" in any of the 2 `page.getByText("Ado Kinnett", { exact: true })`
- shows "29 Cross-Application Avenue, 3000 Bern" in `page.getByText("29 Cross-Application Avenue, 3000 Bern", { exact: true })`
- shows "ado.kinnett@example.com" in `page.getByRole("link", { name: "ado.kinnett@example.com", exact: true })`
- shows "055 222 41 13" in `page.getByText("055 222 41 13", { exact: true })`

### Step 7. Restore Ado Kinnett's original contact details in Customer Management (restores: run even after a failure)

```ts
await page.goto("/");

await customerManagement.customersItemEditProfile.phoneNumberTextbox.fill("055 222 41 13");
await customerManagement.customersItemEditProfile.saveChangesButton.click();
```

Expect 7.1: The original profile is saved and the edit form closes.
- shows "Ado Kinnett" in any of the 2 `page.getByText("Ado Kinnett", { exact: true })`
- shows "Customer Profile" by its text
- shows "Edit Profile" in `page.getByRole("button", { name: "Edit Profile", exact: true })`
- no longer shows "Save Changes" in `page.getByRole("button", { name: "Save Changes", exact: true })`

### Step 8. Open the restored customer profile in Policy Management and verify the original details are shared there too

```ts
await policyManagementPage.goto(new URL("/customers/bunlo9vk5f", process.env.OQAS_BASE_URL_POLICY_MANAGEMENT).href);
```

Expect 8.1: Policy Management displays the restored customer contact details.
- shows "Ado Kinnett" in any of the 2 `page.getByText("Ado Kinnett", { exact: true })`

- shows "ado.kinnett@example.com" in `page.getByRole("link", { name: "ado.kinnett@example.com", exact: true })`
- shows "055 222 41 13" in `page.getByText("055 222 41 13", { exact: true })`
