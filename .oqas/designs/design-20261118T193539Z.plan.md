## 1. customer-name-search-match

Search customers by a matching name fragment (functional level, other, nominal, reads data). Application customer-management, domain customers, functionality customer-search.

- Intent: Verify that a partial first-name match filters the customer list to the matching record.
- Sources: customer-management
- Data: "Ado" (customer-management)

### Step 1. Open the customer list and enter a first-name fragment in Search

```ts
await page.goto("/");
await customerManagement.home.searchTextbox.fill("Ado");
```

### Step 2. Submit the search and verify the matching customer and result count

```ts
await customerManagement.home.searchButton.click();
```

Expect 2.1: Only Ado Kinnett matches the search.
- shows "Ado Kinnett" in `page.getByRole("cell", { name: "Ado Kinnett", exact: true })`
- shows "1 - 1 of 1" in `page.getByRole("columnheader", { name: "1 - 1 of 1", exact: true })`
- no longer shows "Bel Pifford" in `page.getByRole("cell", { name: "Bel Pifford", exact: true })`
- no longer shows "Blondy Langman" in `page.getByRole("cell", { name: "Blondy Langman", exact: true })`

- no longer shows "Bel Pifford" in `page.getByRole("cell", { name: "Bel Pifford", exact: true })`

## 3. customer-profile-open

Open a customer profile from the search results (functional level, other, nominal, reads data). Application customer-management, domain customers, functionality customer-profile.

- Intent: Verify that selecting a matching customer opens that customer's profile and shows the profile details.
- Sources: customer-management
- Data: "Ado" (customer-management)

### Step 1. Open the customer list and search for Ado

```ts
await page.goto("/");
await customerManagement.home.searchTextbox.fill("Ado");
await customerManagement.home.searchButton.click();
```

### Step 2. Open Ado Kinnett's search result and verify profile address and email

```ts
await customerManagement.home.showButtonInRow("Ado Kinnett").click();
```

Expect 2.1: The profile for Ado Kinnett shows their address and email address.
- shows "Ado Kinnett" in any of the 2 `page.getByText("Ado Kinnett", { exact: true })`
- shows "28 Cross-Application Avenue, 3000 Bern" in any of the 22 `page.getByText("28 Cross-Application Avenue, 3000 Bern", { exact: true })`
- shows "akinnetta@example.com" in `page.getByRole("link", { name: "akinnetta@example.com", exact: true })`

## 4. customer-profile-edit-phone

Edit and save a customer's phone number (functional level, other, nominal, writes data). Application customer-management, domain customers, functionality customer-profile-edit.

- Intent: Verify that a changed phone number can be saved and appears on the customer profile, then restore the original data.
- Sources: customer-management
- Data: "055 222 41 11" (customer-management); "055 222 41 12" (made-up)

### Step 1. Open the customer's profile editor

```ts
await page.goto("/customers/bunlo9vk5f/edit_profile");
```

### Step 2. Save a changed phone number and verify the profile shows it

```ts
await customerManagement.customersItemEditProfile.phoneNumberTextbox.fill("055 222 41 12");
await customerManagement.customersItemEditProfile.saveChangesButton.click();
```

Expect 2.1: The profile displays the phone number entered.
- shows "055 222 41 12" in `page.getByText("055 222 41 12", { exact: true })`

### Step 3. Restore the original number by reopening the editor and saving it (restores: run even after a failure)

```ts
await customerManagement.customersItem.editProfileButton.click();
await customerManagement.customersItemEditProfile.phoneNumberTextbox.fill("055 222 41 11");
await customerManagement.customersItemEditProfile.saveChangesButton.click();
```

Expect 3.1: The profile displays the restored phone number.
- shows "055 222 41 11" in `page.getByText("055 222 41 11", { exact: true })`
